
The dashboard analyzes e-commerce data across sales, trends, products, delivery performance, and customer ratings.
The intent was not to invent a dataset, but to recreate and learn the full workflow end to end in Excel.

What’s covered
Sales performance and trend analysis
Product-level insights
Delivery status and fulfillment patterns
Customer ratings and feedback overview

Tools & Features Used
Microsoft Excel
PivotTables and PivotCharts
Slicers and report connections
Bar charts, line charts, and map visuals
Theme and color palette customization

Dataset & Credit
Dataset and dashboard concept are based on learning material from Chandoo.org
The dashboard was fully recreated as a hands-on learning exercise


This project was created to:
Excel dashboarding skills
Learn practical charting and interactivity techniques
